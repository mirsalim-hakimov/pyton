## 📌 Описание проекта

Training Planner — это десктопное GUI-приложение на Python для ведения личного дневника тренировок. Оно позволяет пользователю записывать свои занятия спортом, указывая дату, тип тренировки и её длительность. Все данные сохраняются в локальный JSON-файл, что обеспечивает их сохранность между сеансами работы.

Приложение решает следующие задачи:
- Помогает отслеживать регулярность тренировок
- Позволяет анализировать нагрузку по типам занятий
- Даёт возможность фильтровать историю по дате и типу
- Визуально отображает статистику (количество тренировок и общее время)

### Основные возможности

| Функция | Описание |
|---------|----------|
| ➕ Добавление тренировки | Запись новой тренировки с датой, типом и длительностью |
| 🔍 Фильтрация по типу | Показ только выбранного вида спорта (Бег, Силовая, Йога и др.) |
| 📅 Фильтрация по дате | Показ тренировок за конкретный день |
| 📊 Статистика | Автоматический подсчёт количества тренировок и общего времени |
| 🗑 Удаление | Удаление одной тренировки или полная очистка всех данных |
| 💾 Сохранение | Автоматическое сохранение в JSON при каждом изменении |
| ✅ Валидация | Проверка формата даты и положительного значения длительности |

### Технологический стек

| Компонент | Технология | Назначение |
|-----------|------------|------------|
| Интерфейс | tkinter (ttk) | Создание графического окна, кнопок, таблиц |
| Хранение данных | json | Сохранение тренировок в файл workouts.json |
| Работа с датой | datetime | Проверка формата даты и подстановка текущей |
| Работа с файлами | os | Проверка существования файла с данными |
| Генерация интерфейса | ttk.Treeview | Отображение тренировок в виде таблицы |

## 🚀 Как получить API-ключ

Для Training Planner API-ключ не требуется.

Приложение работает полностью автономно (оффлайн) и не обращается к внешним серверам. Все данные хранятся локально в JSON-файле. Это сделано намеренно, чтобы:
- Не требовалось подключение к интернету
- Данные пользователя оставались приватными
- Приложение было простым в установке и использовании
